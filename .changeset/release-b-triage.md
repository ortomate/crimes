Triage as the front door (Release B). New `crimes triage` command (interactive per-finding walk with five dispositions: `fix-now` / `fix-this-PR` / `needs-design` / `wont-fix` / `scaffolding`; persists to `.crimes/triage.json` with reason + owner + date; non-interactive `--apply` / `--list` / `--clear` / `--retriage`). Triage- and baseline-aware resurfacing: every `crimes scan` outside the resurface base branch (`config.triage.resurfaceBase`, default `"main"`) re-detects findings on files touched in the branch diff and prepends them annotated with `previously_triaged` or `previously_baselined`. New scan flags `--show-triaged`, `--gate-needs-design`, `--gate-resurfaced`. `crimes init --agents` now writes a PreToolUse Edit hook into `.claude/settings.local.json` (plus a forward-looking `.agents/settings.local.json` placeholder); `--no-hooks` opts out. Human renderer rewrites raw score floats as interpretive prose (`blast top-quartile (11 importers)`, `churn 24 commits over 90d · last touched 2 days ago`); JSON output unchanged.

**Breaking-ish: `schema_version` bumps `"0.1.0"` → `"0.2.0"`.** Every `Finding` carries two new **required** fields: `effort` (`"quick" | "small" | "medium" | "large"`) and `fix_shape` (one-line string, ≤120 chars). Consumers that hard-checked `schema_version === "0.1.0"` must accept `"0.2.0"` as well. No existing field changed shape, name, or semantics. `.crimes/baseline.json` and `.crimes/suppressions.json` loaders tolerate both `"0.1.0"` and `"0.2.0"` so upgrading users don't need to hand-edit; the next save migrates the file forward.
