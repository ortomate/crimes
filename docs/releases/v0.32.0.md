# crimes 0.32.0: calibrated from field feedback

JSON schema remains **0.8.0**. Fingerprints of existing findings are unchanged.
0.32 is the first release driven by the per-machine feedback rollup: 54
false-positive verdicts that agents recorded in five repositories against
0.26.0, each re-scanned at the commit it was recorded on. 39 still fired on
0.31.0. This release fixes the patterns behind most of them, and
`diff`/`verdict` stop blaming a branch for findings on files it never
touched.

## Upgrading

Nothing you have recorded stops matching. What you may notice:

- **A new optional field, `outside_change: true`**, on `diff` and `verdict`
  `new_findings` and `fixed_findings`, plus `summary.outside_change`
  (`{ new, fixed }`). It marks a finding whose file and related files are
  unchanged between the two refs. `summary.new` and `summary.fixed` still
  count them.
- **`verdict` no longer weighs those findings, and `--fail-on` on either
  command no longer gates on them.** Pass `--include-outside-change` to
  restore the 0.31 behaviour. A CI gate that failed only because a repo-wide
  percentile moved will now pass.
- **Fewer findings** where the claim was untrue (below). If you suppressed
  any of them, the suppression stops matching anything; `crimes
  audit-suppressions` lists it.
- **`swallowed_error` findings that only parse input are lower**, typically
  medium to low, and say "fails closed".

## What changes

**`diff` and `verdict` (`outside_change`).** Adding one module can move the
repo's p95 fan-in cutoff, so a hub nobody edited becomes a "new"
`high_fan_in_fan_out`. Eight verdicts from one branch said exactly that.
On that branch's range, 0.32 marks those eight and leaves the one fan-in
finding on an edited file unmarked.

**`config_drift`.**

- A name ending in `PUBLISHABLE_KEY`, `ANON_KEY` or `PUBLIC_KEY` is not
  secret-shaped on `KEY` alone, so Supabase's anon and publishable keys are
  no longer reported as **high** client-exposed secrets. `SECRET` or
  `TOKEN` elsewhere in the name still counts. One verdict reported it; the
  rescan found it in four of the five repositories.
- `NODE_ENV` joins `CI` as runtime-provided and is not "undocumented".

**`swallowed_error`.** A `bland_fallback` around nothing but `JSON.parse`,
`decodeURIComponent`, `new URL`, `Intl.*` or a request-body read is failing
closed on malformed input. It stays a finding at reduced severity and
confidence, ranked between documented intent and an unexplained fallback.
A fetch response body (`res.json()`) is excluded: a provider's malformed
body is their failure.

**`name_behavior_mismatch`.** A namespaced factory bound and dereferenced
(`const sf = ts.createSourceFile(…)`) and a factory chained straight into
(`createHash(…).update(…)`) are construction, not side effects.
`.then`/`.catch`/`.finally` chains still count.

**`return_shape_roulette`.** The return type was looked for only before
the first `{`, which is the parameter's type in `fn(input: { … }):
Promise<R>`. Declared return types after inline object parameters are now
seen.

**`duplicated_role_status_plan_check`.** `Promise.allSettled` settlement
statuses (`"fulfilled"`, and `"rejected"` in files that settle promises)
are not a status policy.

**`orphaned_destination`.** A test or story file beside a route is not a
route, and an App Router `route.ts` handler is not a page.

## Measurement

- 0.31.1 (the `config_drift`, `name_behavior_mismatch` and route-test fixes)
  scanned all 22 eval fixtures byte-identically to 0.31.0, so its structural
  baseline was carried forward.
- 0.32.0 changes one fixture finding (`04-monorepo`, a `return_shape_roulette`
  on a function declaring `: Plugin`). Ranking `mean_ndcg_deep` 0.4041 →
  0.4046, deep set unchanged (n=38).
- Live eval round, 134/134 cells: claude 0.87 → 0.85, codex 0.74 → 0.65.
  122 cells received byte-identical input to 0.31.0, and every codex cell
  that moved except one improved `04-monorepo` cell is among them, so the
  codex drop is agent variance on unchanged input, not a product change. It
  exceeds codex's measured ±7pp band and is recorded, not explained.
- The triage of all 54 entries is in
  [`docs/dogfooding/2026-11-12-rollup-triage.md`](../dogfooding/2026-11-12-rollup-triage.md).

## Still unsettled

- `direct_date` at a request boundary: a route that reads the clock once
  and injects it inward is still charged (8 verdicts, all low). It needs the
  parser to follow a clock read into a call argument.
- `magic_domain_literal_scatter` and `duplicated_policy` on a field name
  shared by unrelated state machines.
- No outside trial outcome has been collected.
