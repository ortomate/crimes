# crimes 0.29.0 — preparation

This version is in development and is not a claim of npm publication.
The follow-up focuses on analysis latency, completed agent edits and recovery
of existing decisions. JSON schema remains **0.8.0**.

## Changes under verification

- Source reads and extracted JS/Python parse data are reused within each
  analysis, with a bounded memory budget and no persistent cache.
- Coverage exclusion matching is batched while retaining the same matcher.
- Pin migration stages all replacements, retains original bytes for process
  interruption recovery, and provides `migrate-pins --recover`. The recovery
  JSON envelope is additive; prior report fields remain unchanged.
- The outcome benchmark has twelve behavioral tasks, explicit host/model
  settings and three conditions: no crimes, supplied context, installed
  workflow. Six tasks are held out from tuning. The old three-task runner is
  replaced; historical results remain historical evidence.
- [Performance methods](../performance.md), [migration recovery](../pin-migration.md)
  and a [self-serve external trial](../external-trial.md) document the workflows.

## Evidence

Verification and the host matrix are in progress. Preliminary timings are
not release acceptance, and pilot measurement corrections are not product
improvements. The final notes will record complete results, failures,
method changes and unresolved limits before this version is proposed for release.
